Order Management


DOne
POST /api/orders - Create new order
GET /api/orders - Get all orders (with filters)
GET /api/orders/:orderId - Get order details with items
PATCH /api/orders/:orderId/status - Update order status

Order Items
POST /api/orders/:orderId/items - Add items to order
DELETE /api/orders/items/:itemId - Remove item
PATCH /api/orders/items/:itemId/status - Update item status (kitchen)



pending
GET /api/orders/active - Get active orders
GET /api/orders/kitchen - Kitchen display system 

Payments (Bill Splitting)

POST /api/orders/:orderId/payments - Add payment
GET /api/orders/:orderId/payments - Get all payments for order

Discounts

POST /api/orders/:orderId/discount - Apply discount

Reports

GET /api/orders/reports/daily-sales - Daily sales summary
GET /api/orders/reports/payment-summary - Payment method breakdown

✨ Key Features

Automatic Calculations (via DB triggers)

Order totals (subtotal, tax, service charge)
Payment status (unpaid/partial/paid)
Table occupancy
Timestamps for status changes


Bill Splitting

Split payment across multiple methods
Automatic payment status updates
Track transaction IDs


# 🔥 MUST-HAVE ORDER APIs (POS)



## 2️⃣ Payment APIs (Critical)

### 💳 Add Payment

```http
POST /orders/:id/payments
```

Handles:

* Partial payments
* Multiple methods
* Triggers payment_status update

---

### 🔄 Refund Payment

```http
POST /orders/:id/refunds
```

Handles:

* Partial refunds
* Payment reversal logic
* Audit trail

---

### 🧾 Get Payments for Order

```http
GET /orders/:id/payments
```

---




### 🔁 Bulk Item Update (Kitchen)

```http
PATCH /orders/:id/items/status
```

Example:

```json
{
  "item_ids": ["uuid1", "uuid2"],
  "status": "preparing"
}
```

---

## 4️⃣ Kitchen Display System (KDS) APIs

### 🍳 Kitchen Queue

```http
GET /orders/kitchen
```

Returns:

* Active orders
* Items grouped by status
* Time elapsed

---

### ⏱️ Mark Item Ready

```http
POST /orders/items/:itemId/ready
```

---

### 🚨 Delayed Orders

```http
GET /orders/delayed?minutes=20
```

---

## 5️⃣ Table & Floor APIs

### 🔄 Move Table

```http
POST /orders/:id/change-table
```

Payload:

```json
{
  "table_id": "new-table-uuid"
}
```

---

### 🔗 Merge Orders

```http
POST /orders/merge
```

Used when:

* Guests change tables
* Split/merge bills

---

### ✂️ Split Order

```http
POST /orders/:id/split
```
